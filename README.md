# Projeto Gamepedia - Frontend

Projeto desenvolvido para estudo de Angular 18 + Spring Boot + MySQL

## Descrição

O Gamepedia é um sistema de CRUD de jogos desenvolvido para fins de estudo, utilizando Angular 18 no frontend, Spring Boot no backend e MySQL como banco de dados. O projeto permite listar, cadastrar, editar e excluir jogos, além de popular o banco de dados com dados de exemplo.

## Funcionalidades

- Listar jogos
- Cadastrar novos jogos
- Editar jogos existentes
- Excluir jogos
- Popular banco de dados com dados de exemplo

## Tecnologias Utilizadas

- Angular 18
- Bootstrap 5
- Ngx-Datatable
- Moment.js
- Spring Boot
- MySQL

## Requisitos

- Node.js
- Angular CLI
- Backend do projeto configurado e rodando
